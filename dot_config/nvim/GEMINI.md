# Project Overview

This is a Neovim configuration based on NvChad. It's designed to be a personalized development environment with a focus on a wide range of programming languages and a dynamic theme that integrates with `pywal`.

The configuration uses `lazy.nvim` for plugin management and includes a variety of plugins for features like code formatting, linting, code running, and a custom `pywal`-based theme.

# Building and Running

This is a Neovim configuration, so there is no "building" or "running" in the traditional sense. To use this configuration, you would typically clone it to your `~/.config/nvim` directory.

The configuration relies on the following external dependencies:

*   **Neovim (v0.11+):** The editor itself.
*   **NvChad:** The base configuration.
*   **`pywal`:** For the dynamic theme.
*   **A Nerd Font:** For the icons and symbols in the UI.
*   **LSP Servers:** A variety of LSP servers are configured, which need to be installed separately (e.g., via `mason.nvim`).

# Development Conventions

The configuration uses `stylua` for Lua code formatting, `prettier` for web development files, and `shfmt` for shell scripts. Formatting is configured to run on save.

The configuration is structured to be modular, with different features and settings separated into different files under the `lua` directory. Custom plugins are defined in `lua/plugins/init.lua`, and custom NvChad settings are in `lua/chadrc.lua`.

The theme is dynamically generated by the `pywal/chadwal.py` script, which is executed when Neovim starts. This script watches for changes in the `pywal` color scheme and automatically updates the Neovim theme.

# Key Files

*   **`init.lua`:** The main entry point for the Neovim configuration. It initializes `lazy.nvim` and loads the plugins.
*   **`lua/chadrc.lua`:** The main file for overriding NvChad's default configuration.
*   **`lua/plugins/init.lua`:** Defines the custom plugins used in the configuration.
*   **`lua/configs/lspconfig.lua`:** Configures the LSP servers for different languages.
*   **`pywal/chadwal.py`:** A Python script that dynamically generates the Neovim theme based on the `pywal` color scheme.
*   **`.stylua.toml`:** Configuration for the `stylua` code formatter.

# Usage

To use this configuration, you would:

1.  Clone this repository to `~/.config/nvim`.
2.  Install the required dependencies (Neovim, NvChad, `pywal`, Nerd Font).
3.  Start Neovim. The plugins will be automatically installed by `lazy.nvim`.
4.  Run the `:MasonInstallAll` command to install the configured LSP servers, formatters, and linters.
